# DaTikZ-v3

**Source:** HuggingFace dataset [`nllg/datikz-v3`](https://huggingface.co/datasets/nllg/datikz-v3)
**Downloaded:** 2026-10-24 — **test split only**

TikZ / LaTeX figure generation from captions.

`data/test-00000-of-00001.parquet` — **542 rows** (`caption`, `code`, `image` PNG bytes, `pdf`, `uri`, `origin`, `date`), 32MB.

**Not downloaded:** `train` (145366 rows, 6.3GB).

**Why v3 and not v4:** `nllg/DaTikZ-V4` — and the mirrors / derivatives (YangruiWANG, Praha-Labs, explcre) — are **train-only, with no test split**. So v3's test set is the DaTikZ eval set.
